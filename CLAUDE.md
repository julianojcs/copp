# Projeto: O SGE é um sistema completo de gerenciamento de eventos projetado para congressos médicos e eventos científicos desenvolvido em Next.js + TypeScript + MongoDB + Mongoose + React.Js

## 👤 Persona
- Atue como Desenvolvedor Senior Fullstack.
- Priorize performance, tipagem estrita e segurança.

## 📏 Code Standards
- **Padrão:** Sempre use **Early Return** para falhas e validações.
- **Tipagem:** Proibido o uso de `any`. Use `unknown` ou interfaces específicas.
- **Async:** Sempre utilize `async/await` com blocos `try/catch`.

## Princípios
- **Clean Code**: nomes descritivos, funções pequenas e focadas, sem código morto
- **Clean Architecture**: separação de responsabilidades, dependências apontam para dentro
- **DRY**: reutilizar componentes existentes antes de criar novos
- **YAGNI**: não implementar funcionalidade especulativa

## Idioma
- Código e variáveis: inglês
- Mensagens de UI e erro: português (pt-BR)
- Commits: inglês, sem referência ao Claude

## Git
- Mensagens de commit em inglês
- Nunca incluir "Co-Authored-By", "Generated by Claude" ou qualquer referência ao Claude

## 📅 Datas e Timezone
- **Timestamps** (createdAt, deadlines, horários): usar `formatInTimezone(date, format)` de `@/lib/date-utils` — respeita timezone do sistema (`America/Sao_Paulo`)
- **Date-only** (data de evento, nascimento, dia de atividade): usar `formatDateOnly(date, format)` de `@/lib/date-utils` — interpreta como UTC
- **Nunca** usar `toLocaleDateString()`, `toLocaleString()` ou formatar datas manualmente
- **Nunca** usar `formatDateOnly` para timestamps com horário — o resultado ficará errado
